# BUSINESS_MODEL.md

## Business Positioning
Clinic Voice Room serves as both a free partner benefit for existing marketing clients and a future standalone hospital-device interpretation package for non-partner hospitals.

The current product direction is a provisioned Android two-device package for doctor/patient interpretation, with the web app retained for staff/admin workflows and usage review.

## Plans
- `partner_free`: existing marketing clients, free but usage tracked
- `external_trial`: future trial hospitals
- `external_paid`: future paid hospitals using the device package and web admin tools

## MVP Business Requirement
Every room must be attributable to hospital, staff, language, and usage duration from the first version.
